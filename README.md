## 🖼️ How to Add Your Profile Picture

The portfolio includes an automated profile image loader inside the 3D hologram avatar frame:

1. Place your photo inside this folder (`c:\Users\cayhe\Desktop\portfolio\`).
2. Name the file:
   ```
   profile.jpg
   ```
3. Refresh your browser! The website will automatically detect `profile.jpg` and display your picture inside the cybernetic HUD avatar frame. If `profile.jpg` is not present, a fallback cyber silhouette graphic is displayed automatically with zero broken image icons.
